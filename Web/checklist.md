### 2. Работа с Charles (Breakpoints)

| Проверка | Что демонстрирует |
|----------|-------------------|
| TW47–TW49 — статус «Курьер на месте» при подмене `status: 2` | Умею подменять ответы сервера для воспроизведения труднодостижимых состояний |
| TW52–TW57 — статус «Ну всё, теперь кататься» при подмене `finished: true, status: 2, inDelivery: false` | Работа с несколькими параметрами в одном ответе |
