### БР4 — Приложение падает при многократной смене ориентации экрана

| Поле | Значение |
|------|----------|
| **Приоритет** | 🔴 Критический |

| **Шаги** | 1. Перейти из портретной ориентации в альбомную.<br>2. Перейти обратно в портретную.<br>3. Повторить шаги 1–2 несколько раз. |
| **Ожидаемо** | Приложение не падает. |
| **Фактически** | Приложение упало. |

| **Скриншоты** | БР4 |

**Что показывает:** воспроизведение краша по накопительному сценарию + разбор лога Logcat.
